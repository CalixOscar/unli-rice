# Mac App Store screenshots — Unli Rice 1.4 (2026-10-29)

Upload this folder's images, in order, as the Mac screenshot set (2880x1800, no alpha).

Captured from a development build of 1.4 pointed at a throwaway demo vault ("Recipe Box" and
"Garden Planner", twelve made-up notes, one Claude Code connection recorded by the real MCP
server), never real notes. Projects and To do were switched on in Setup › Extras, as they are
for anyone upgrading from 1.3. The window filled the screen; `fit` trimmed the title bar and
rounded corners and repeated one plain pixel row (the last row, or a gap between cards for 05 and 06) to reach 16:10, so nothing is cropped from the UI.

projects have no git folders, so every card reads "No recorded status yet").
