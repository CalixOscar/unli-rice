# INTENT-005 — Project Garden in Unli Rice

**Date:** 2026-10-19
**Author:** founder, via Codex
**Status:** approved scope — founder requested “merge the two, place the garden inside unli rice for a quick overview”
**Plan:** docs/PLAN-project-garden.md

## The problem

Project Garden makes project stories and local activity understandable together, but it is a separate browser dashboard with hardcoded stories from a vault export. Unli Rice already owns the live notes, folder grants, next-step conventions, and repository snapshots. Moving between the two hides the context needed to resume a project.

## What solved looks like

One visible Garden destination inside the Mac app gives a quick, searchable overview of projects, recorded status, next steps, open to-do notes, and the repository facts the app can actually read. A project can lead directly to its related notes. Data carries its source and date; missing data never means zero work or a healthy project. A customer without studio scripts or memory.md can use it with existing notes and a folder selected in Setup.

## Scope

Native, read-only Mac overview, using existing folder grants, notes, and optional existing repository snapshots. Preserve Garden's calm cards and plain language. Include projects without Git. The standalone Project Garden remains reference material; its historical stories must not become bundled current facts.

No new server, network requests, dependencies, permissions, persistent registry, note writes, sync formats, Git command runner, activity score, or App Store upload. Detailed commit charts and GitHub account integration can follow separately.
