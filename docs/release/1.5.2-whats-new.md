# Mac 1.5.2

AI assistants can now preview matching notes and read several selected notes together, with limits on how much text the new tools return. Existing search and reading tools remain available. Assistants need to choose the new tools; this update does not promise lower usage for every search.

The To Do list now recognises branches whose work is already included in a branch saved on GitHub, instead of reporting that work as saved only on this Mac.

The Engineering Guardrails starting template has been refreshed. Your saved notes, House Rules and drafts are unchanged; choose the template if you want to use the new wording. Older saved template text may now be labelled “Your own rules”; its contents are preserved.

## GitHub release detail

Two read-only connector tools: `search_note_summaries` and `get_notes_batch`, with response-size limits, paging and per-note availability. No note migration or rewrite.

The synthetic benchmark returned 24% fewer bytes and made 77% more calls over 24 tasks. Broad searches benefited; narrow searches often cost more. Bytes are not tokens, and real-assistant savings have not been measured. See `docs/BENCH-compact-retrieval.md`.

Mac release only. Capture remains 1.3.1 (13).
